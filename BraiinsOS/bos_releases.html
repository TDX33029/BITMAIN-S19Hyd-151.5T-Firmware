Braiins OS 26.10 adds Russian and Chinese translations and the ability to uninstall Braiins OS from the web UI, reduces unnecessary bosminer restarts when changing tuner targets or pool groups, and improves fan, PSU, and sysupgrade reliability across several platforms.

Antminer S19 & S21 Series

Features

  • Added Russian and Chinese language support to the GUI.
  • Added the ability to uninstall Braiins OS from the web UI.
  • Boost fan speed automatically when chip temperature climbs quickly, for faster thermal response.
  • Added the chip number to "dangerous internal temperature" error messages for clearer diagnostics.
  • Removed the max_fan_efficiency_mode Advanced setting.

Bug Fixes

  • Fixed Bosminer API reporting setting the same tuner target as an error, which caused an unnecessary bosminer restart.
  • Fixed tuner mode switches (power and hashrate target) in the GUI restarting bosminer.
  • Fixed stalled PSU I2C communication on Zynq control boards.
  • Unified the reporting of real hashrate on the dashboard.
  • Verified update packages prior to upgrade on AML, BBB and CVITEK platforms
  • Fixed the automatic-upgrade status showing a stale last-execution time.
  • Changed PSU command failure warnings to appear only after retries are exhausted, reducing log noise.
  • Fixed the Antminer S19 XP+ Hyd. tuning failing with a "PLL: requested frequency out of range" error when the water temperature was hot.
